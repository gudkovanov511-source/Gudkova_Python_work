# Документация проекта (Урок 10)

## Описание базового синтаксиса записи и форматирования

Проект представляет собой набор автотестов для проверки работы двух веб-приложений: калькулятора и интернет-магазина. 
В работе используются следующие технологии:
1. **Python**: Основной язык для написания тестов.
2. **Selenium WebDriver**: Инструмент для управления браузером (эмуляция действий пользователя).
3. **Pytest**: Фреймворк для запуска тестов и параметризации.
4. **Allure**: Инструмент для создания наглядных отчетов.

### Форматирование кода
- Код написан с соблюдением стандарта PEP 8.
- Для описания действий используются декораторы `@allure.step` и `with allure.step()`.

## Инструкция по запуску тестов для формирования отчета Allure,

1. Убедитесь, что у вас установлены все зависимости (если есть файл `requirements.txt`):
```bash
pip install -r requirements.txt
```
2. В терминале выполните команду по запуску тестов (будут запущены оба теста):
 ```bash
pytest --alluredir=./allure-results
```

##  Инструкция по просмотру результатов теста

1. Чтобы сгенерировать и открыть интерактивный отчет в браузере, выполните:
```bash
allure serve ./allure-results
```
2. В открывшемся отчете Allure вы увидите:

- **Название теста:** Динамическое, например: "Проверка сложения 7 + 8 с задержкой 45 секунд".

- **Severity (Критичность):** blocker (для калькулятора: так как калькулятор должен работать идеально) и critical (для интернет-магазина: проверяется простой путь покупателя на котором программа должна работать без сбоев).

- **Продолжительность** Время, потребовавшееся для прохождения теста

- **Описание теста** Пояснение к проводимому тесту

- **Шаги теста:** Открытие сайта, установка задержки, клики по кнопкам, ожидание и проверка результата.

- **Результат:** Статус прохождения (Passed) или информация об ошибке с указанием фактического и ожидаемого результатов.
